# carrier_discount_data

## 1. 목적

[통신사할인알림 앱](https://github.com/ssh0291/carrier_discount_app)이 쓰는 할인 매장 목록이 바뀔 때마다 앱을 통째로 다시 빌드·재설치하지 않아도 되게 하려고, 목록 데이터만 앱 코드와 분리해서 여기 따로 둔다.

## 2. 소개

SKT/KT/LG U+ 멤버십 제휴 할인 브랜드 목록(`benefits.json`) 데이터 저장소. 비밀 정보가 전혀 없어서 공개(Public)로 둔다.

## 3. 개요 (전체 작동 흐름)

1. **언제**: 매주 토요일 새벽 3시
2. **무엇이**: 국내 개인 서버에 등록해둔 예약 작업(크론)이
3. **어떻게**:
   - SKT/KT/LG U+ 공식 페이지를 다시 긁어서(`carrier_discount_app` 저장소의 `tools/collect-benefits/collect.js`) 최신 `benefits.json`을 만들고
   - 그 결과를 이 저장소에 올린다(push)
   - `통신사할인알림` 앱은 실행될 때마다 아래 주소에서 이 파일을 받아와 내부에 저장해두고, 이후 매장 검색에 그 내용을 쓴다

```
https://raw.githubusercontent.com/ssh0291/carrier_discount_data/main/benefits.json
```

즉 **이 저장소의 `benefits.json`만 갱신되면, 사용자는 앱을 그대로 둔 채 다음 실행부터 새 목록을 받는다.** (GitHub의 raw 콘텐츠는 갱신 직후 최대 5분 정도 이전 내용을 보여줄 수 있음)

## 4. 제작 툴

| 이름 | 용도 | 비용 |
|---|---|---|
| Node.js | 통신사 페이지에서 목록을 수집하는 스크립트 실행 | 무료 |
| 국내 개인 서버 | 매주 자동 수집·업로드(크론 작업) | 이미 운영 중이던 서버 재사용, 추가 비용 없음 |
| GitHub | 이 목록 파일을 저장하고 앱에 배포 | 무료 |

## 5. 제작 히스토리

- **2026-09-27**: 통신사 페이지 최초 수집 (379개 브랜드).
- **2026-09-29**: 앱 자동 갱신용으로 저장소 최초 생성. GitHub Actions로 매달 자동 수집을 시도했으나, LG U+ 수집 서버가 해외/클라우드 IP를 막는 문제로 실패 → 저장소·자동화 전체 삭제.
- **2026-09-30**: 국내 개인 서버의 주 1회(토요일 새벽 3시) 크론 작업으로 수집 방식을 바꾸면서 저장소 재생성.

## 6. 주안점

- 이 저장소에는 **비밀 정보를 절대 넣지 않는다** (통신사 공식 페이지에 이미 공개된 혜택 정보만 담음). 그래야 앱이 로그인 없이 자유롭게 받아갈 수 있다.
- 수집은 반드시 **국내 IP(개인 서버)**에서 실행해야 한다 — LG U+ 쪽 API가 해외/클라우드 서버 IP를 막기 때문이다.

## 7. 주의사항

### benefits.json 구조

```jsonc
{
  "collectedAt": "2026-09-27",
  "counts": { "total": 379, "included": 254, "needsReview": 125 },
  "brands": [
    {
      "brand": "GS25",          // 매장명. 앱은 지도 검색 결과 상호명에 이 문자열이 포함되는지로 매칭한다
      "category": "편의점",
      "status": "included",     // "included"만 앱이 실제로 사용함
      "carriers": {
        "SKT": {
          "tiers": {             // 등급별 혜택 문구. "ALL"/"전등급" = 등급 무관 공통 혜택
            "VIP": "매주 화요일, 프레시 푸드 1천 원당 200원 할인"
          },
          "conditions": "이용 조건 원문"
        },
        "KT": null,
        "LGU": null
      }
    }
  ]
}
```

- `status`가 `"included"`인 것만 앱이 쓴다.
- `brand`(브랜드명)를 바꾸면 지도 검색 결과와 매칭이 깨질 수 있으니, 이름 자체는 함부로 바꾸지 않는다.

### 갱신이 잘못됐을 때

- 국내 서버의 크론 로그(`collect.log`)에서 수집 개수가 평소(약 254개 "included")보다 크게 줄었다면, 통신사 페이지 구조가 바뀌었거나 접속이 막힌 것일 수 있다 — 이럴 땐 이 저장소를 갱신하지 말고 먼저 원인을 확인해야 한다.

## 8. 삭제 안내 (더 이상 쓰지 않을 경우)

- 국내 서버의 크론 작업(매주 토요일 새벽 3시, `carrier_discount_app` 관련) 삭제 — "서버 관리자" 세션 또는 서버 관리자에게 요청.
- 이 저장소 자체 삭제: 저장소 Settings 맨 아래 "Delete this repository".
- 비용이 나가는 항목은 없다(전부 무료 등급/기존 서버 재사용).
